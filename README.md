# نظام تحصيل الإيجار — مكتب مزون الشرق

تطبيق ويب لإدارة المستأجرين وتحصيل الإيجار الشهري، مبني بـ Next.js وقاعدة بيانات Supabase الحقيقية (حساب دخول فعلي، بريد استعادة كلمة مرور حقيقي، وبيانات متزامنة بين كل الحسابات والأجهزة).

هذا الدليل يشرح خطوة بخطوة كيف تُنشئ حساب Supabase المجاني وتربطه، ثم كيف تنشر الموقع على الإنترنت مجانًا عبر Vercel. لا تحتاج أي خبرة برمجية — فقط اتبع الخطوات بالترتيب.

---

## الجزء الأول: إنشاء قاعدة البيانات (Supabase)

### 1. إنشاء حساب ومشروع

1. اذهب إلى [supabase.com](https://supabase.com) واضغط **Start your project**، وسجّل حساب مجاني (يمكنك استخدام GitHub أو بريدك الإلكتروني).
2. اضغط **New Project**.
3. اختر اسمًا (مثلاً `mazoon-alsharq`)، وكلمة مرور قوية لقاعدة البيانات (احفظها في مكان آمن)، والمنطقة الأقرب لك (مثل Frankfurt أو Bahrain إن توفرت).
4. اضغط **Create new project** وانتظر دقيقة أو دقيقتين حتى يجهز.

### 2. إنشاء الجداول

1. من القائمة الجانبية، افتح **SQL Editor**.
2. اضغط **New query**.
3. افتح الملف [`supabase/schema.sql`](supabase/schema.sql) الموجود في هذا المشروع، انسخ محتواه بالكامل، والصقه في المحرر.
4. اضغط **Run**. سيتم إنشاء كل الجداول، والصلاحيات، وقائمة الغرف والمحلات (٤٨ وحدة) تلقائيًا.

### 3. الحصول على مفاتيح الربط

1. من القائمة الجانبية: **Project Settings** ← **API**.
2. انسخ القيمتين:
   - **Project URL**
   - **anon public** key
3. ستحتاجهما بعد قليل.

### 4. إنشاء حساب الإدارة والحسابين للاطلاع (٣ حسابات)

1. من القائمة الجانبية: **Authentication** ← **Users** ← **Add user** ← **Create new user**.
2. أنشئ ٣ مستخدمين بهذه الطريقة (بريد إلكتروني + كلمة مرور لكل واحد)، وفعّل **Auto Confirm User** لكل واحد منهم:
   - حساب الإدارة (الصلاحيات الكاملة) — استخدم بريدك الشخصي.
   - حساب اطلاع ١
   - حساب اطلاع ٢
3. الحسابان الثاني والثالث سيصبحان تلقائيًا "للاطلاع فقط" (لا يمكنهما التعديل) — هذا هو الافتراضي في النظام.
4. لجعل الحساب الأول **إدارة كاملة**: افتح **SQL Editor** من جديد، وشغّل هذا الاستعلام بعد استبدال البريد بالبريد الذي استخدمته:

   ```sql
   update profiles set role = 'admin'
   where id = (select id from auth.users where email = 'ضع-بريد-حساب-الإدارة-هنا@example.com');
   ```

### 5. إعداد روابط استعادة كلمة المرور

1. من القائمة الجانبية: **Authentication** ← **URL Configuration**.
2. في **Site URL** ضع رابط موقعك بعد نشره على Vercel (ستحصل عليه في الجزء الثاني، ويمكنك تعديل هذا الحقل لاحقًا).
3. في **Redirect URLs** أضف:
   - `http://localhost:3000/auth/confirm` (للتجربة المحلية)
   - `https://رابط-موقعك-في-فيرسل.vercel.app/auth/confirm` (بعد النشر)

## الجزء الثاني: نشر الموقع (Vercel)

### 1. رفع المشروع إلى GitHub

إذا لم يكن لديك حساب GitHub، أنشئ واحدًا مجانًا على [github.com](https://github.com)، ثم أنشئ مستودعًا (repository) جديدًا وارفع مجلد `mazoon-rent-tracker` إليه.

### 2. النشر على Vercel

1. اذهب إلى [vercel.com](https://vercel.com) وسجّل حساب مجاني (الأسهل: تسجيل الدخول بحساب GitHub نفسه).
2. اضغط **Add New** ← **Project**، واختر المستودع الذي رفعته.
3. في خطوة **Environment Variables** أضف المتغيرين التاليين (القيم التي نسختها من Supabase في الخطوة ٣ أعلاه):
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. اضغط **Deploy** وانتظر دقيقة حتى يكتمل النشر. ستحصل على رابط مثل `https://mazoon-rent-tracker.vercel.app`.
5. ارجع لإعدادات Supabase (الجزء الأول، الخطوة ٥) وحدّث **Site URL** و**Redirect URLs** بالرابط الفعلي.

بعد هذه الخطوات، الموقع يعمل بشكل كامل: تسجيل دخول حقيقي، استعادة كلمة مرور عبر البريد، وبيانات متزامنة بين جميع الأجهزة والحسابات الثلاثة.

## التجربة محليًا على جهازك (اختياري)

```bash
npm install
cp .env.local.example .env.local
# ضع فيه Project URL و anon key من Supabase
npm run dev
```

ثم افتح `http://localhost:3000`.

## ملاحظات مهمة

- **حساب الإدارة** هو الوحيد الذي يمكنه إضافة/تعديل/حذف المستأجرين وإنهاء العقود.
- **حسابا الاطلاع** يريان فقط صفحة "المعلومات" (الدخل، التأمين، المسددين) دون أي إمكانية تعديل.
- حالة "غير مسدد" تُحتسب تلقائيًا في بداية كل شهر ميلادي ما لم تُعلّم كمسدد يدويًا.
- عند "إنهاء العقد" تصبح الغرفة/المحل شاغرة تلقائيًا ويُنقل المستأجر لسجل تاريخي دائم.
- يمكن تغيير كلمة مرور أي حساب أو إضافة/حذف حسابات لاحقًا من **Authentication → Users** في لوحة تحكم Supabase.
